# 🧠 Retail AI Optimization System

A smart retail AI dashboard that optimizes pricing, monitors inventory, forecasts demand, and more.

## 🚀 Features

- 🔐 User Authentication (Login / SignUp / Role-based)
- 📥 Add Daily Sales Records
- 📊 Dashboard for sales trend, inventory, pricing
- ⚙️ Optimization Suggestions (inventory transfers, price)
- 📁 View Raw Data from SQLite DB
- 🔧 Admin Tools to initialize/reset/generate data

## 🛠️ Tech Stack

- **Frontend:** Streamlit
- **Backend:** Python
- **Database:** SQLite
- **Visualization:** Matplotlib
